# PocketMoney Manager 

I built this project because I personally struggle with tracking my monthly spending. Many times my money gets over and I don’t know where I spent it. So I created this simple Java program to track daily expenses.


##  What this project does

This is a console-based expense tracker that allows you to:
- Add your daily expenses
- View all expenses
- Calculate total money spent
- Save data in a file for future use


##  Requirements

- Java (JDK 8 or above)
- Any terminal or command prompt


##  How to run the project

1. Download the file `PocketMoneyTracker.java`
2. Open terminal in that folder
3. Compile the code:
   javac PocketMoneyTracker.java
4. Run the program:
   java PocketMoneyTracker


##  How to use the program

After running, you will see a menu like:

1. Add expense  
2. View expenses  
3. Show total spent  
4. Exit  

###  Option 1:
Enter:
- Date  
- Category  
- Amount  
- Description  

###  Option 2:
Shows all saved expenses  

###  Option 3:
Displays total money spent  

###  Option 4:
Exits the program and saves data  


##  Data Storage

All expenses are saved in a file named `expenses.txt`.  
Make sure to exit using option 4 so your data gets saved properly.

This project is made as part of Java BYOP to solve a real-life problem faced by students.
